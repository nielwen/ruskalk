## 🚀 Neste steg for bedre SEO

### 1. **Domain og hosting**
```bash
# Sett opp custom domain
# scoring-tool.nielsens-tools.com
# eller
# ruskalk-scoring.no
```

### 2. **Google Search Console**
- Registrer domenet
- Submit sitemap.xml
- Overvåk søkeytelse
- Fix eventuelle crawling-feil

### 3. **Content marketing**
- Skriv blogginnlegg om bruk av skjemaene
- Lag videoer om hvordan verktøyet brukes
- Del på profesjonelle nettverk (LinkedIn)

### 4. **Teknisk forbedring**
```bash
# Installer PWA-funksjonalitet
npm install workbox-cli
# Legg til service worker for offline bruk
```

### 5. **Ytelse (Core Web Vitals)**
- Optimaliser bilder
- Minifier CSS/JS
- Implementer caching
- Bruk CDN
